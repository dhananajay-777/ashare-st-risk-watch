# Data (not included)

The notebooks use one file, `Copy of ST_data.xlsx` (sheet `ST_data`): 62,669 firm-years for 5,365 China A-share listed firms, 2001-2024, with financial ratios, governance fields and ST / *ST status. It was built from the ZxData A-share firm-year dataset.

**The data is licensed for academic use only, so it is not in this repository**, and neither are any scores or firm-level outputs. If you have your own licensed copy, put it here as `data/Copy of ST_data.xlsx` (or set the `ST_DATA_PATH` environment variable) and run the notebooks top to bottom.

`.gitignore` blocks Excel, CSV, model and output files so they cannot be committed by accident.
